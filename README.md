Gym2

Pet-проект на Java для практики разработки и применения знаний на практике.

🛠 Технологии
Java 25
Apache Maven
📋 Требования

Для запуска проекта необходимы:

JDK 25
Maven
🚀 Установка и запуск
Клонируйте репозиторий:
git clone https://github.com/AvgustIS/Gym2.git
Перейдите в директорию проекта:
cd Gym2
Соберите проект:
mvn clean package
Откройте проект в IntelliJ IDEA или другой совместимой IDE и запустите главный класс приложения (main).
📁 Структура проекта

Gym2/
├── src/
│   └── main/
│       └── java/
├── pom.xml
└── .gitignore
🎯 Цель проекта

Проект создан для практики программирования на Java, изучения инструментов разработки и совершенствования навыков написания кода.
